# Подготовка публикации

Выполнили: Фурсов Артем и Сподриков Матвей.

Проект можно запускать локально на Windows с .NET 9 SDK. Команда публикации:

```powershell
dotnet publish -c Release -o .\publish
```

Приложение использует Windows winsqlite3.dll, поэтому для текущей версии необходим Windows-хост. До публикации необходимо заменить демонстрационные пароли, настроить HTTPS, создать резервное копирование SQLite, защитить доступ к App_Data и провести аудит. Для работы в нескольких процессах требуется переработать хранение и транзакции. Оплата не реализована.

Для собственного Git-репозитория в папке проекта выполните `git init`, `git add .`, затем создайте коммит. Создайте удалённый репозиторий в выбранном сервисе и настройте remote. Не добавляйте `App_Data`, `bin` и `obj`; фотографии, использованные пользователем, следует публиковать только при наличии прав на их распространение.

Публичный сайт и удалённый репозиторий не созданы: адрес, хостинг и аккаунт не предоставлены.
