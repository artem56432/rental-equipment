# RENTA — запуск и описание

Выполнили: Фурсов Артем и Сподриков Матвей.

Требования: Windows 10/11, .NET 9 SDK. Откройте PowerShell и выполните:

```powershell
cd -LiteralPath "C:\Users\Пользователь\Documents\Codex\2026-11-17\1-figma-er-ui-ux-2\outputs\EquipmentRental"
dotnet run
```

Если приложение уже запущено, сначала нажмите Ctrl+C. Адрес будет указан после `Now listening on`. Обновите браузер Ctrl+F5. При первом запуске программа импортирует App_Data/store.json в App_Data/renta.db. Исходный JSON остаётся резервной копией; после импорта актуальные данные хранятся в SQLite. Не запускайте одновременно две копии с одной базой.

| Роль | Логин | Пароль |
|---|---|---|
| Клиент | anna@renta.ru | demo |
| Менеджер | manager@renta.ru | demo |
| Администратор | admin@renta.ru | demo |

Администратор редактирует категории, цены, товары, количество единиц, ремонт, списание и роли. Менеджер подтверждает бронь, оформляет выдачу и возврат. Стоимость сохраняется на момент бронирования; штраф за просрочку — суточная ставка за каждый полный календарный день после плановой даты возврата, плюс введённая сумма повреждения. Фотографии товаров находятся в wwwroot/images.

## Ограничения учебной версии

SQLite хранит пользователей, категории, оборудование, бронирования, единицы склада и их историю в отдельных таблицах. Старый снимок app_state сохраняется как резерв при миграции. Номера присваиваются автоматически; менеджер выбирает свободный номер при выдаче. Изменение количества в ремонте и списании автоматически распределяет состояния по номерам. Несколько одновременно работающих процессов не поддерживаются. Платежи не реализованы; суммы в статистике — начисления. Тестовые учётные записи используют простой пароль и предназначены для локального демонстрационного запуска. Для публичной публикации нужна дополнительная защита, настройка HTTPS и надёжного хранения данных.
