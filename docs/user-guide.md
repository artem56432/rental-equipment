# Руководство пользователя

Выполнили: Фурсов Артем и Сподриков Матвей.

1. Запустите проект по инструкции README.md и откройте адрес из PowerShell.
2. Войдите или зарегистрируйтесь. В каталоге выберите товар и даты; оба дня включаются в срок аренды. Система проверит число исправных единиц на каждый день.
3. В разделе «Мои аренды» видны заказы, стоимость, статусы и отмена до выдачи.
4. Менеджер открывает раздел «Менеджер», подтверждает заказ, оформляет выдачу и при возврате указывает состояние и штраф за повреждение. Просрочка рассчитывается при возврате.
5. Администратор открывает «Админ»: добавляет и редактирует товары и категории, назначает роли, указывает общее количество, количество в ремонте и списанное количество. Склад не позволяет уменьшить число исправных единиц ниже занятости активных броней.
6. Раздел «Статистика» показывает начисленные суммы, число заказов и распределение по категориям и статусам. Фактическую оплату приложение не учитывает.


При выдаче менеджер выбирает инвентарный номер из списка свободных исправных экземпляров. Номер показывается в строке заказа. До изменения складского состояния примите выданные экземпляры.
